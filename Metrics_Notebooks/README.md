
This repository contains everything needed to generate metrics, plots, figures, etc. for the report

## 📁 False Positives/Negatives
The file `False_Positive_and_Negative_Score.ipynb` is used to get the False Positive and Negative metric between a prediction mask and GT

***

## 📁 Dice/clDice
The file `dice_and_cldice.ipynb` is used to get the dice and cldice score

***

## 📁 Inference Results from VesselFM Adaptation Method
The file `Preprocessing_and_Inference.ipynb` is used to output predicted masks for VesselFM Adaptation Method

***

## 📁 Dice
The file `GNN-Dice_Score.ipynb` is used to calculate the dice of an individual mask compared against GT

***
